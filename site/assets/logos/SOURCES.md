# Logo sources

The product marks are inlined as `<symbol>` elements in `index.html` so they
follow the page's light/dark theme. They belong to their owners and are used
only to identify the agents classmcp works with. classmcp is not affiliated
with any of them.

| Symbol id    | Product     | Source |
| ------------ | ----------- | ------ |
| `l-codex`    | OpenAI (Codex) | OpenAI mark served inline on <https://developers.openai.com/codex> |
| `l-claude`   | Claude Code | Simple Icons `claudecode` (source <https://code.claude.com>), brand color `#D97757` |
| `l-opencode` | OpenCode    | Simple Icons `opencode` (source: `packages/identity/mark.svg` in the OpenCode repository) |
| `l-cursor`   | Cursor      | Simple Icons `cursor` (source <https://cursor.com/brand>) |
| `i-github`   | GitHub      | Simple Icons `github` (source <https://github.com/logos>) |

Simple Icons version 16.36.0.

Fonts in `site/assets/` are Geist and Geist Mono under the
SIL Open Font License; their license files sit next to the `.woff2` files.
