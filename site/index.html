From install
to first answer.

Let your agent do the setup.

Set up the classmcp MCP server for me end to end. The npm package is gcrclassmcp and the command is classmcp. Read https://github.com/khurrambhutto/classmcp first.

1. Check the environment
   - Node.js 20 or newer. If it is missing or older, stop and tell me what to install.
   - Check whether classmcp is already installed before installing it again.

2. Install
   - Run npm install --global gcrclassmcp@next, then classmcp --version.

3. Connect Google
   - Guide me through creating a Google Cloud project, enabling the Classroom and Drive APIs, configuring the OAuth consent screen, and downloading Desktop app credentials. I complete the browser steps. Never ask me for credentials in chat.
   - Run classmcp setup interactively and let me approve Google's consent page myself.
   - Run classmcp doctor and explain any failure without printing secrets.

4. Register the server
   - Identify my MCP host: Codex, OpenCode, Claude Code, Cursor, or another stdio host. If you are unsure, ask me.
   - Register classmcp with the README instructions for that host. Merge into the existing config and keep the other servers and comments.
   - Use the global executable or a stable absolute path, never an npx cache path.

5. Tell me what to do next
   - Tell me to restart my host so the server loads.
   - Confirm these five tools are listed: get_overview, get_assignment, search, download_files, submit_work.
   - Give me this first request: "What's due this week in my Google Classroom courses?"
   - Tell me that submissions are best effort, and that Google may require me to finish a turn-in in Classroom.

Do not skip a verification step. If something fails, stop and tell me exactly what failed and how to fix it.

Or do it yourself

1

Install the package

The package is gcrclassmcp; the command is classmcp. Node.js 20 or newer. 

npm install -g gcrclassmcp@next
classmcp --version
2

Connect Google

Create a Desktop OAuth client, then let setup walk you through the sign-in.

Google Cloud, step by step
  1. Open Google Cloud Console and create a project.
  2. Enable the Google Classroom API and the Google Drive API.
  3. Configure the OAuth consent screen. For a personal account, choose External; while the app is in Testing, add yourself as a test user.
  4. Create an OAuth client ID with application type Desktop app.
  5. Download the JSON to your Downloads folder. Setup finds client_secret*.json there. 
classmcp setup
classmcp doctor
3

Register it with your agent

Run in your terminal:

Terminal 
codex mcp add classmcp -- classmcp serve
codex mcp list

Restart or reconnect Codex after registering the server.

First request

Ask your agent to list your courses. A get_overview call with view: "courses" means you’re connected. An empty list is still a working connection.

!

One honest limit.

Google only lets the app that created an assignment attach files or turn work in. For teacher-created coursework, classmcp can upload your file to Drive but can’t push it into the assignment. You get a link and finish the turn-in in Classroom.

What exactly is classmcp?

A local Model Context Protocol server that connects a coding agent to your Google Classroom account. It exposes five tools: overview, assignment detail, search, file downloads, and best-effort submissions.

Which agents can I use?

Any host that supports local MCP servers over stdio. Setup examples cover Codex, OpenCode, Claude Code, Cursor, and Antigravity. Codex and OpenCode registration were checked live for this release candidate; the other examples have not all been validated.

Do I need my own Google Cloud project?

Yes. Create a project, enable the Classroom and Drive APIs, and download Desktop app credentials. The steps above cover it. Your school’s Workspace policies can still restrict what a third-party app may access.

Can my agent turn in my assignments?

Best effort, and only with your explicit confirmation. Google blocks attaching and turning in work on coursework created by another project, which covers most teacher-created assignments. You get a Classroom link to finish.

Is it free?

classmcp is MIT licensed, with no subscription and no hosted tier. Your agent may have its own costs. The current npm release is 0.3.0-rc.1.

Something didn’t connect. Where do I start?

Run classmcp doctor: it checks credentials, token storage, API connectivity, and host configuration. Run classmcp setup again if you need to re-authorize, or see the troubleshooting guide.
