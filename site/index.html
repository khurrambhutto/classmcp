Set up classmcp, the Google Classroom MCP server, for me.

1. Fetch https://khurrambhutto.github.io/classmcp/llms-full.txt and read all of it before doing anything. Follow its "Agent setup procedure" in order. (If you cannot fetch URLs, read README.md in https://github.com/khurrambhutto/classmcp instead.)
2. Work out which MCP host you are.
   - Codex, OpenCode, or Claude Code: use that host's section of the guide exactly.
   - Any other host: first read your host's official MCP documentation to find its config file, key names, and reload steps, then register the server in that format.
3. I will do the Google Cloud Console and consent steps in my browser. Walk me through them. Never ask me to paste, and never print, my client secret or tokens.
4. Run classmcp setup interactively (or ask me to run it in my own terminal if yours can't take input), then classmcp doctor.
5. Register classmcp without breaking my existing config: merge, keep other servers and comments, never use an npx cache path.
6. Verify: after a restart, the five tools get_overview, get_assignment, search, download_files, submit_work are listed, and get_overview with view "courses" succeeds.

If any step fails, stop and tell me the exact error and the fix from the guide's Troubleshooting section.

Privacy and limits

Nothing hosted

Your computer talks straight to Google with your own OAuth client. No account, no backend, no analytics.

Contained files

Files stay in ~/Downloads or your CLASSMCP_WORKDIR. Downloads never overwrite or follow symlinks.

Careful writes

Uploads and turn-ins are never retried. Turn-in needs the exact phrase I confirm turn in.

Submissions

Google lets only the app that created an assignment attach files or turn it in. For teacher-made work, classmcp uploads to Drive and gives you the Classroom link to finish.

FAQ

What is classmcp?

A local Model Context Protocol server that connects a coding agent to your Google Classroom account. It exposes five tools — get_overview, get_assignment, search, download_files, submit_work — plus classroom:// resources for hosts that read them.

Which agents work with it?

Any host that can start a local stdio MCP server. Setup covers Codex, OpenCode, Claude Code, and Cursor; Codex and OpenCode were checked live for this release. For any other host, follow its MCP docs and register the command classmcp with the argument serve.

Why do I need my own Google Cloud project?

There’s no classmcp service in the middle. Your own Desktop OAuth client means your tokens only go between your computer and Google. School Workspace policies can still block third-party apps.

Can my agent turn in assignments?

Best effort, and only after explicit confirmation. Google returns 403 @ProjectPermissionDenied for most teacher-created coursework, so submit_work uploads your file to Drive and returns blocked: true with a Classroom link to finish there.

Where are my credentials stored?

The OAuth client is in ~/.classmcp/credentials.json (mode 0600). Tokens go to the OS keychain, or ~/.classmcp/tokens.json when no keychain is available. Override the folder with CLASSMCP_CONFIG_DIR.

Is it free?

Yes — MIT licensed, no subscription, no hosted tier. Your agent may have its own costs. Current release: 0.3.0-rc.1 on npm.

How do I uninstall?

Run npm uninstall --global gcrclassmcp, remove the classmcp entry from your agent’s config, and delete ~/.classmcp if you don’t need the stored credentials.
